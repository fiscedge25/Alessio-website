## 9. DIRETTIVE DI DESIGN

### Palette colori
| Ruolo | Colore | Hex |
|---|---|---|
| Background principale | Nero profondo | `#0a0a0a` |
| Background elevato | Grigio scurissimo | `#111111` |
| Superficie | Grigio scuro | `#181818` |
| Bordi | Bianco 6% opacità | `rgba(255,255,255,0.06)` |
| Bordi hover | Bianco 12% opacità | `rgba(255,255,255,0.12)` |
| Testo primario | Bianco caldo | `#f0efe9` |
| Testo secondario | Grigio medio | `#8a8a8a` |
| Testo muted | Grigio scuro | `#555555` |
| Accento | Beige/Champagne | `#c8c0b0` |

### Typography
| Ruolo | Font | Peso |
|---|---|---|
| Titoli / Display | Cormorant Garamond (serif) | 300, 400 |
| Body / UI | DM Sans (sans-serif) | 300, 400, 500 |

### Stile generale
- **Estetica:** Dark premium, futuristico ma elegante, linee morbide non rigide
- **Animazioni background:** Particle network con connessioni tra nodi, interazione mouse
- **Effetti:** Grain overlay sottile, scroll-reveal fade-up, hover transitions fluide
- **Layout:** Asimmetrico dove serve, ampio spazio negativo, sezioni ben separate con divider sottili
- **NO:** Colori vivaci, stile cartone/giocoso, font generici (Inter, Roboto, Arial), gradients viola, layout cookie-cutter

### Struttura sezioni
1. **Hero** — Nome grande in serif italico, tagline, CTA buttons
2. **About** — Bio + statistiche in card con bordi
3. **Education** — Timeline verticale con punti animati
4. **Projects** — Grid 2×2 con card cliccabili e link ai siti
5. **Skills** — 3 colonne (Strategy, Technical, Languages) con dot rating
6. **Contact** — CTA centrale con link email, LinkedIn, portfolio
7. **Footer** — Copyright minimale

## 10. PROMPT D'AZIONE

### Prompt base per costruire la landing page

```
Costruisci una landing page personale professionale per Alessio Sabatino 
usando le informazioni contenute in questo file MD come fonte dati completa.

DESIGN:
- Palette: nero (#0a0a0a), bianco caldo (#f0efe9), accento beige (#c8c0b0), 
  sfumature di grigio
- Typography: Cormorant Garamond per titoli, DM Sans per body
- Background: particle network animato su canvas con interazione mouse + 
  grain overlay sottile
- Stile: premium, futuristico ma elegante, linee morbide, ampio spazio negativo
- Animazioni: scroll-reveal fade-up, hover transitions fluide, navbar blur on scroll

SEZIONI:
1. Hero con nome in serif grande + tagline + 2 CTA buttons
2. About con bio + 3 statistiche in card
3. Education con timeline verticale animata
4. Projects con grid 2x2 di card cliccabili (tutti i link funzionanti)
5. Skills con 3 colonne e dot rating system
6. Contact con link email, LinkedIn, portfolio
7. Footer minimale

REQUISITI TECNICI:
- Single-file HTML con CSS e JS inline
- Mobile responsive con hamburger menu
- Google Fonts via CDN
- Tutti i link ai progetti devono aprire in nuova tab
- Performance: niente librerie pesanti, vanilla JS per animazioni
```
